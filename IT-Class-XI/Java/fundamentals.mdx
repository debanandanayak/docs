## Object oriented programming

1. Java is an Object Oriented Programming language.
2. In OOP language program is collection of objects that interact with other object to solve a problem.
3. It follows bottom up approach in designing a program.
4. Its primary focus is on safety and security of data in program rather operation of program.
5. It supports concept of Inheritance and Polymorphism.

## Concpet of OOP

1. Class
2. Data
3. Data member
4. Method

## What is Java Class

1. Class is physical or logical entity that has certain attributes (data), behavior (method).
2. It is like a template which defines how information will be managed.
3. It encapsulates data and methods together in a single unit.
4. To use attributes of a class its object must be declared.

## What is java Object

1. Object is instance of a class in java that is capable of holding actual data in memory locations.
2. Both Class and Objects are related to each other as data type and variables.
3. To use attributes and invoke method of class must be associated with its corresponding object.
4. From a class multiple objects can be declared and all objects can have the same type of data members.

## Designing a class

1. A class contain Data and Method.
2. Methods are set of sequential steps written together to perform a specific task on the data.

## Access modifier

1. Access Modifiers in java are keywords that specify the accessibility scope of data members of class.
2. Java offers following Access Modifiers:
   - private
   - public
   - protected

### private access modifier

1. Members defied as private of a class cannot be accessed outside of the class.
2. Data member should be kept as private to avoid vulnerable to security issues.

### public access modifier

1. Members defined as public of a class cab be accessed outside of the class.
2. Member methods are generally kept as public to make them available to access.

### protected access modifier

1. Members defined as protected can be accessed within class and its derived class.
2. Data members can be kept as protected.

## Variables & Data Types

### variables

1. Variable is a placeholder for data that can change its value during program execution.
2. Technically, a variable is the name for a storage location in the computer’s internal memory and the value of the variable is the contents at that location.

### Data type

1. Data type determines the type of data to be stored in a variable.
2. Data type tells the compiler, how much memory to reserve when storing a variable of that type.

|Data type|Type of values |Size     |
|byte     |integer        |8-bit    |
|short    |integer        |16-bit   |
|int      |integer        |32-bit   |
|long     |integer        |64-bit   |
|float    |floating-point |32-bit   |
|double   |floating-point |64-bit   |
|char     |character      |16-bit   |
|boolean  |True or False  |1-bit    |

## Rules for naming variable

1. Variable names can begin with either an alphabetic character, an underscore (_), or a dollar sign ($).
2. Variable names must be one word. Spaces are not allowed in variable names. Underscores are allowed.
3. There are some reserved words in Java that cannot be used as variable names, for example – int
4. Java is a case-sensitive language. Variable names written in capital letters differ from variable names with the same spelling but written in small letters.


## Control strcture

A program is considered as finite set of instructions that are executed in a sequence. But sometimes the program may require executing some instructions conditionally or repeatedly. In such situations java provides:

1. Selection structure
2. Repetition structure


## Selection strcture

Selection in program refers to Conditionals which means performing operations (sequence of instructions) depending on True or False value of given conditions.

## if-else statement

Selection in program refers to Conditionals which means performing operations (sequence of instructions) depending on True or False value of given conditions. Structure of Conditional in a program can be as follow:

```java
if (condition) {
    // code to be executed if condition is true
} else {
    // code to be executed if condition is false
}```

## if-else-if statement

Selection in program refers to Conditionals which means performing operations (sequence of instructions) depending on True or False value of given conditions. Structure of Conditional in a program can be as follow:

```java
if (condition1) {
    // code to be executed if condition1 is true
} else if (condition2) {
    // code to be executed if condition2 is true
} else {
    // code to be executed if condition1 and condition2 are false
}```

## switch-case statement

Selection in program refers to Conditionals which means performing operations (sequence of instructions) depending on True or False value of given conditions. Structure of Conditional in a program can be as follow:

```java
switch (expression) {
    case value1:
        // code to be executed if expression matches value1
        break;
    case value2:
        // code to be executed if expression matches value2
        break;
    default:
        // code to be executed if expression does not match any case
}
```
